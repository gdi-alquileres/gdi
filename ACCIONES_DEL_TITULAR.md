# Lo único que debe hacer el titular de GDI

Para continuar con el despliegue real hacen falta cuentas externas que deben quedar bajo control del titular de GDI:

1. Crear una cuenta en GitHub (o usar una existente) y un repositorio privado.
2. Crear una cuenta en Render.
3. Crear/usar una cuenta Expo.
4. Más adelante: Apple Developer, Google Play Console y Mercado Pago Developers.

No compartir contraseñas ni secretos por chat. Las credenciales se cargan directamente en las plataformas correspondientes.
